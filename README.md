# Superstore Sales Analysis

## Project Overview
This project analyzes Superstore sales data using LibreOffice Calc to understand sales performance, profitability, and regional trends.

## Tools Used
- LibreOffice Calc
- Spreadsheet formulas
- Charts and dashboard visualization

## Key Performance Indicators
- Total Sales: ₹14,956,982
- Total Profit: ₹3,747,121.20
- Profit Margin: 25.05%

## Analysis
- Sales performance by category
- Sales and profit by region
- Discount impact on sales and profit
- Category-wise profit margins

## Dashboard
Screenshots of the dashboard and key findings are included in this repository.

## Objective
To practice spreadsheet-based data analysis and present business insights through a clear dashboard.
